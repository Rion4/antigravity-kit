# Contributing to Antigravity Kit

We welcome contributions to Antigravity Kit! Please follow these guidelines:

1.  **Fork the repository** on GitHub.
2.  **Create a branch** for your changes (e.g., `fix/my-bug` or `feature/new-feature`).
3.  **Make your changes** and ensure they are well-documented.
4.  **Write tests** for your changes.
5.  **Submit a pull request** with a clear description of your changes.

## Code Style

*   Follow the existing code style.
*   Use descriptive variable names.
*   Write clear and concise comments.

## Commit Messages

*   Use a concise and descriptive commit message.
*   Include a reference to the issue being addressed (if applicable).

## Questions?

If you have any questions, please open an issue or reach out to the maintainers.
